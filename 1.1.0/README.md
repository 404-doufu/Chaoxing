# 发行 1.1.0 · tofu

1.1.0 新增液态玻璃界面、轻弹性切换动画与精简自动化设置。更新内容见 [CHANGELOG.md](CHANGELOG.md)。

面向 Edge / Chrome + 脚本猫的学习通用户脚本。单文件安装，自行配置兼容 Chat Completions 的模型 API，支持 DeepSeek 或自己的服务。

## 下载与安装

正式文件：[发行1.1.0.user.js](发行1.1.0.user.js)。**只安装这一份**，无需安装配套脚本或开发工具。

1. 在浏览器中安装脚本猫扩展，启用用户脚本运行权限。
2. 打开本仓库的 `发行1.1.0.user.js`，通过 **Raw / 原始文件** 获取完整代码。
3. 在脚本猫中新建普通脚本，将默认模板全部替换为该文件的完整内容，保存并启用。也可通过脚本猫导入此文件。
4. 打开学习通课程，或刷新整个课程页面。总控标题应显示 **tofu · 学习通总控 v1.1.0**。
5. 首次使用会在浮窗中打开 API 配置，填写自己的 API 地址、模型名和 Key，保存配置并测试连接。

从 1.0.0 或旧测试版升级时，先禁用旧正式脚本、旧主脚本和旧独立后台监督脚本，只保留 1.1.0 启用，防止重复运行。相同脚本猫存储中的既有 API 设置可沿用；不同浏览器的配置不会自动互通。

## 配置 API

- **API 地址**：服务商提供的兼容 Chat Completions 接口地址；可填写服务根地址或 `/v1` 地址，也可填写完整 `/chat/completions` 地址。
- **模型名**：填写该服务实际提供的模型 ID。DeepSeek 用户也应按自己账号可用的模型填写。
- **API Key**：填写自己的 Key，仅保存在脚本猫存储中；发行文件不含任何人的 Key。
- 自定义服务域名已支持，无需编辑脚本头。脚本猫提示访问授权时，核对你配置的服务地址后授权。

模型调用会把题干、选项及已有填空内容发送给你配置的 API，并按其规则计费。不要把 Key 写入源码或提交到 GitHub。

## 功能与使用

- 唯一置顶液态玻璃浮窗，半透明磨砂、高光边缘与柔和阴影，可拖动、收起并记住位置；API 配置在同一窗口内。不支持背景模糊时使用浅色底保证可读。
- 收起、展开与 API 切换采用约 460 毫秒的轻弹性高度动画；文字保持原字号，窗口与内容区裁切遮挡。快速反向操作从当前显示高度继续；系统开启“减少动态效果”时直接切换。“刷新当前页”与其他普通按钮使用相同的玻璃样式。
- 按页面顺序串行播放音视频，前一个实际结束并获平台确认后才交接；切换前至少停留 10 秒。
- 文档滚动至末尾、处理懒加载及分页，随后复核平台完成状态。
- 支持单选、多选、判断、文字填空，保留已填答案；支持已有 UEditor 富文本空位。图片及未知题型提示人工处理。
- 自动音视频、自动文档、自动切章、AI 答题、自动提交和自动保存统一开启，不再在浮窗显示六项开关。首次使用本版本会将旧关闭值统一开启一次；保留 API 配置、倍速与暂停状态。保留总暂停、继续和停止 AI 按钮。
- 自动切章；当前章节目录对钩可确认完成。无进展时至少间隔 10 秒重载本节内容，累计两次后再停滞 10 秒跳过，跳过不会冒充平台完成。
- 内置页面级心跳监督、有限重试、暂停/继续和停止 AI，无需第二份脚本。

验证码、登录失效、未知页面和浏览器拒绝自动播放时需要人工处理。页面关闭、浏览器冻结或电脑休眠时，内置页面监督不能保证继续运行或唤醒；10 秒停留也不是平台保证允许的访问频率。答案应按需要核对，模型输出不保证正确。

安装、配置与使用说明统一放在本 README，发行脚本中不嵌入用户说明或整段许可正文。

## 开发与验证

普通使用者无需这些步骤。构建与贡献说明见 [CONTRIBUTING.md](CONTRIBUTING.md)，安装 Node.js/npm 与 Python 后执行：

```powershell
npm ci
npm run build
npm run check
npm test
```

修改 `src/` 或构建工具后重新构建，不直接修改发行文件。构建链为：参考脚本与源码 → `build/legacy.user.js` → 稳定开发产物 → `发行1.1.0.user.js`。

`package.json.stableVersion=1.1.0` 是公开发行版本；`version=1.1.1` 仅是内部兼容构建版本。构建过程会生成两份稳定开发/回归脚本，普通用户使用上面的单文件发行。`build/` 保存可重建中间产物，不随源码发布。维护者运行 `npm run package:release` 可整理版本目录与 ZIP；已有同名发布目录不会被覆盖。

当前 **286 项本地测试通过**，构建和语法检查通过；本地浏览器已检查收起/展开、API 往返、快速反向、边界裁切和按钮样式，这不等于真实 Edge/Chrome 全课程或长期后台验收。本次没有安装浏览器脚本、调用真实用户 API 或发布到 GitHub。
