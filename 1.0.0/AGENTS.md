# 工作区接续规则

- 开始工作先读 `PROJECT_CONTEXT.md`；安装与命令看 `README.md`，不要反复扫描全部历史对话。
- 工作区推荐安装版本以 `package.json` 的 `stableVersion` 为准；`version` 是内部兼容构建版本。浏览器实际安装版本需单独核对。
- 正式发行入口为 `发行1.0.0.user.js`，作者 tofu，由 `tools/build_release.py` 生成；单文件内置页面级监督。用户说明统一放在 `README.md`，完整许可使用独立文件，脚本只保留必要元信息和简短来源声明，不重新嵌入面向用户的文档。两份旧名稳定脚本保留为开发/回归产物，不与发行版同时启用，不将页面监督描述为可唤醒关闭或冻结页面的独立后台任务。
- 修改 `src/` 中的源码，用 `npm run build` 生成安装脚本；不要只改生成文件。
- `build/legacy.user.js` 是必要的自动生成中间文件，不是推荐安装版本。不要重新生成根目录的旧别名脚本。
- 必须保留页面顺序串行音视频、至少 10 秒停留、平台完成复核、文档翻阅、自动切章、个人 API 答题和后台监督。
- 用户已授权 2.1.4 恢复规则：当前章节目录对钩可独立确认完成；无任务进展 10 秒刷新本节内容，累计最多两次，之后再停滞 10 秒可跳过本章。跳过只记录恢复状态，不能伪造平台完成。活动 AI、未结束媒体、确认弹窗、暂停/离线/验证阻断期间不刷新或跳过。
- 稳定版 UI 仅由最外层课程页持有一份可拖动的置顶总控；子 iframe 不生成面板，API 设置嵌入该浮窗。不要恢复旧多面板生成入口。
- 任务接口数组顺序不等于页面播放器顺序；身份有歧义时等待，不能猜测并启动后面的播放器。
- 页面路由、题目容器和确认窗统一维护在 `src/page-adapter.js`，不要在多个模块复制旧路由或依赖单一按钮函数名。确认窗回归须覆盖题目 iframe 与课程顶层 `workpop`、确定/提交按钮、多步确认及同页测验排队。
- Key 只保存在脚本猫存储；不要读取、记录、硬编码或在接续文档保存真实 Key、Cookie、认证 URL。
- 变更后运行适当检查，最终执行 `npm run build`、`npm run check`、`npm test`。报告实际结果和实页验收边界。
- `参考脚本.txt` 与 `LICENSE` 保持独立；搜索优先使用 `rg`，排除 `node_modules/`、`build/` 与安装脚本中的大段生成内容。
- 不将本地模拟测试或用户反馈写成当前 Edge 已实测通过；浏览器权限/连接受限时如实记录。
