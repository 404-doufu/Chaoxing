# 本地特殊字体适配

章节测验使用 `font-cxsecret` 将一部分文字编码到其他 Unicode 位置，DOM 文本可能与用户看到的文字不同。答题模块只解析当前页面已经内嵌的 TrueType 字体，按 `cmap`、`loca`、`glyf` 提取字形并匹配本地字形摘要。只替换带该字体类的文字，不改动平台页面和提交数据格式。

`src/data/font-signatures.json` 保存 20,945 条 SHA-1 字形摘要到唯一汉字的事实映射；存在多个不同汉字的相同摘要不纳入。未知字形、字体未加载、字体格式错误均跳过相关题目并给出原因；不让模型猜测乱码，不上传字体或题目给其他识别服务。

指纹索引数据来源：[TellMeYourWish/chaoxing_solution_of_font_confusion](https://github.com/TellMeYourWish/chaoxing_solution_of_font_confusion)。没有复制或运行该项目的 Python/JS 代码。离线导入工具 `tools/import_font_signatures.py` 使用严格限定的无行为数据占位对象读取索引，安装脚本不使用 pickle、不依赖 Python/字体工具、不在线下载索引。输入文件 SHA-256：

- `HanSansCN_CmapTables.pkl`：`78ab61655817560f619aaaf89e23555e53d0750022da36a89c290d6c0fe97942`
- `HanSansCN_glyfHashedTables.pkl`：`d192fd6f32db69805b585c760b3d325177522b59fa158b996339df125ade04ca`

原字形来自 Adobe [Source Han Sans CN Normal](https://github.com/adobe-fonts/source-han-sans)，字体版本 1.000。字体遵循 SIL Open Font License 1.1，完整许可单独保存在 [SourceHanSans-OFL.txt](licenses/SourceHanSans-OFL.txt)，不更改工程原有 `LICENSE`。测试字体 `tests/fixtures/quiz-font.ttf` 是页面内嵌的 10 KB 子集，仅含字形与字体元数据，无 API Key、Cookie、登录参数或题目答案。

`tests/fixtures/blank-font.ttf`（约 7 KB）是填空题页面内嵌的字形子集，用于验证新随机编码的题干仍可完整还原；同样不含凭据或题目答案，沿用上述字体许可。

当前算法适配该字形族；平台更换字形轮廓后需要更新本地索引，不能宣称覆盖所有可能字体。
